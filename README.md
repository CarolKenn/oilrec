# 油耗记录 · 加油记账（移动端 Web App）

按 7 张设计稿还原的手机竖屏油耗记录应用，**纯静态站点**（无构建、无依赖、无后端），
可直接拖到 Netlify 上线，iOS Safari / Android Chrome 均可正常显示与操作。

```
index.html              单页应用外壳（5 个视图 + 底部标签栏 + 弹窗）
css/app.css             全部样式（浅色/深色 + 蓝/绿/橙三套强调色 + 安全区适配）
js/core.js              本地存储、演示数据、油耗与统计计算
js/charts.js            SVG 折线图 / 柱状图（自适应宽度）
js/export.js            导出 xlsx / json / csv，导入 xlsx / csv / json（表头自动识别）
js/xlsx.js              纯前端读取 .xlsx：inflate 解压 + zip 解析 + 工作表 XML 解析
js/views.js             首页 / 详单 / 记账 / 我的 / 我的统计 视图渲染
js/app.js               路由、事件、弹窗、表单联动、图片压缩
manifest.webmanifest    PWA 配置（可“添加到主屏幕”，竖屏 standalone）
netlify.toml            发布目录与缓存/安全响应头
assets/icon.svg         应用图标
```

## 计算口径

- **油耗**：两次“加满跳枪”之间的累计加油量 ÷ 累计行驶里程 × 100；中间没加满的记录会并入下一段累计，
  不影响精度，只是结算时间延后到下一次加满。选了“上次没记录”的记录会切断累计，避免把漏记的段算错。
- **估算油耗**：一次满箱结算都还没有时（例如刚开始用、或习惯每次加 200 元从不加满），
  用 **累计加油量 ÷ 累计里程 × 100** 给出近似值，界面显示为 `≈` + 「估算」徽标；
  默认回看最近 12 次加油，里程不足 300 公里时扩大到全部记录，低于 100 公里不给值。
  首尾油箱余量不同会带来偏差，跑得越多越准；加满两次后自动换成精确值。
- **详单逐行**：没结算的记录不显示 `--`，而是给一个滚动累计的参考值（`≈` + 「估算」小字），
  取最近 12 段的加油量 ÷ 里程，累计不足 200 公里才退回 `--`；最早一条是计算起点，显示 `-- 起点`。
  这个值是「到这条为止的平均」，下次加满会被精确值替换，所以前后会有跳变，属正常。
- **平均油耗**：按里程加权（Σ加油量 ÷ Σ里程 × 100），不是简单平均；取不到实测值时同样退化为估算。
- **平均油费**：区间实付金额 ÷ 区间行驶里程；**平均行程**：里程 ÷ 天数。
- **总计优惠**：Σ(机显金额 − 实付金额)。
- **参考低位油耗**：按当前车辆的排量 + 进气形式查表估算（同排量涡轮机比自吸高约 0.5～1.0 升），
  用于首页趋势图的参考虚线与「表现优秀 / 表现良好 / 油耗偏高」评级，按车辆分别保存。

| 排量 | 1.0 | 1.2 | 1.4 | 1.5 | 1.6 | 1.8 | 2.0 | 2.4 | 2.5 | 3.0 | 3.5 | 4.0 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 自然吸气 | 5.3 | 5.6 | 5.9 | 6.2 | 6.5 | 7.0 | **7.5** | 8.6 | 8.9 | 10.2 | 11.5 | 12.6 |
| 涡轮增压 | 5.6 | 6.1 | 6.7 | 7.0 | 7.3 | 7.8 | **8.4** | 9.4 | 9.6 | 10.8 | 11.9 | 12.9 |

表中没有的排量按相邻两档线性插值；要改数值直接编辑 `js/core.js` 的 `REF_TABLE`。
同一弹窗里还有 **±0.5 步进的微调**（范围 −2.0 ～ +2.0）：常跑高速往下调、市区偏多往上调，
最终参考值 = 查表值 + 微调，按车辆独立保存在 `engine.offset`。

## 底部导航

`油耗`（首页）· `详单` · `记录`（记一笔 / 编辑）· `我的`；“我的统计”从「我的 → 统计报表」进入，
支持按月翻页、按年翻页、自定义起止日期，统计加油次数/油费/油量/里程/平均油耗/每公里油费/平均油价/日均里程/单次油费，
并给出当月明细或按月汇总。

## 本地预览

```bash
# 任选其一
python -m http.server 5173
npx serve .
```

浏览器打开 http://localhost:5173 ，用开发者工具切到手机模拟（390 × 844）。

## 部署到 Netlify

**方式一（拖拽）**：Netlify 控制台 → Sites → Add new site → Deploy manually，把本目录整个拖进去即可。

**方式二（CLI）**：

```bash
npm i -g netlify-cli
netlify deploy --prod --dir .
```

**方式三（Git）**：仓库连到 Netlify，发布目录填 `.`，构建命令留空（`netlify.toml` 已配置）。

## 数据说明

- 数据保存在浏览器 `localStorage`（key `oilrec.v1`），只在当前设备可见，**清除网站数据会丢失**，
  建议定期在“我的 → 数据管理”里导出备份。
- 首次打开会写入一份 2023-03 ~ 2026-11 的演示数据（38 条），方便直接看到图表效果；
  “我的 → 清空所有记录”即可清空当前车辆的全部记录。
- 导入支持 `.xlsx` / `.csv` / `.json`，会**自动扫描前 15 行找表头**，按列名匹配（日期时间、总里程、机显单价、加油量、机显金额、实付金额、优惠、油号、加满、亮灯、漏记、加油站、备注等常见写法都能识别）；
  多工作表时自动选中带“日期 + 里程”的那一张；日期支持 `2026-10-07 19:18`、`2026/10/7`、`20261007`、Excel 序列号（含小数时间）；“是/否、有/无、亮/没有亮、已跳枪/未跳枪、1/0”都能转成开关；旧版 `.xls` 需先另存为 `.xlsx`。
- 换设备迁移：导出 JSON → 新设备“从文件恢复数据”。
